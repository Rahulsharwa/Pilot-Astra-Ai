## Theme behavior

Default dark, regardless of operating-system theme. Only `pilot-astra-theme` is stored. The HTML attribute selects tokens scoped to post-hero regions, inner shells and footer; it applies no hero colors. The original white hero, scroll transition and dark final scene remain identical in either preference. Light mode adds a separate 95px gradient inside the existing ecosystem background, without height changes. White n8n/WordPress assets get a contrast-supporting background with identical dimensions. The shared toggle is absolutely positioned in existing header whitespace; original header bounds at the baseline viewport are unchanged.

Accessible name describes the next action; aria-pressed=true means light active. Native button supports Enter/Space, 40px tap target and visible focus. Storage exceptions leave in-memory switching usable. Storage events synchronize tabs. No new packages, backend, body inversion, body color override, duplicate header, scroll lock or animation engine.
